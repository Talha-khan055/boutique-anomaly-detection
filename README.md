# Anomaly Detection in Boutique Transaction Data

## Project Overview

This project aims to identify unusual purchase patterns in Aanchal Boutique transaction data.

The goal is to build a data analysis workflow that loads transaction data, explores it, detects anomalies, and displays results through an interactive dashboard.

## Technologies Used

- Python
- Pandas
- Git and GitHub
- SQL
- Scikit-learn
- Streamlit

## Project Tasks

1. Generate synthetic boutique transaction data.
2. Perform Exploratory Data Analysis (EDA).
3. Write SQL queries to answer business questions.
4. Build an Isolation Forest anomaly detection model.
5. Create an interactive Streamlit dashboard.
