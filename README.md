# \# Anomaly Detection in Boutique Transaction Data

# 

# \## Project Overview

# 

# This project aims to identify unusual purchase patterns in Aanchal Boutique transaction data.

# 

# The goal is to build a data analysis workflow that loads transaction data, explores it, detects anomalies, and displays results through an interactive dashboard.

# 

# \## Live Dashboard

# 

# \*\*Streamlit App:\*\* https://boutique-anomaly-dashboard.streamlit.app/

# 

# \## Technologies Used

# 

# \- Python

# \- Pandas

# \- NumPy

# \- Git and GitHub

# \- SQL

# \- Scikit-learn

# \- Streamlit

# \- Matplotlib

# 

# \## Project Tasks

# 

# 1\. Generate synthetic boutique transaction data.

# 2\. Perform Exploratory Data Analysis (EDA).

# 3\. Write SQL queries to answer business questions.

# 4\. Build an Isolation Forest anomaly detection model.

# 5\. Create an interactive Streamlit dashboard.

# 

# \## Dashboard Features

# 

# \- Interactive transaction date range filter.

# \- Total transaction count.

# \- Total sales calculation.

# \- Flagged anomaly count.

# \- Table displaying flagged transactions.

# 

# \## How to Run Locally

# 

# Install the required libraries:

# 

# ```bash

# pip install -r requirements.txt

# ```

# 

# Run the Streamlit dashboard:

# 

# ```bash

# streamlit run app.py

# ```

# 

# To train the anomaly detection model:

# 

# ```bash

# python model.py

# ```
